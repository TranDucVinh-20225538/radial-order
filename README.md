# radial-order

Code and numerical tables for the order-inversion checks.

The result tables belong in `aistats-checks/`. Embedding matrices (`*.npy`), raw images, checkpoints, and credentials do not belong in this repository.

Upstream image sources keep their own licenses (HAM10000 is CC BY-NC 4.0, BCN20000 and the PAD-UFES-20 raw data are CC BY 4.0, WILDS Camelyon17 is CC0, WILDS iWildCam is CDLA Permissive 1.0). This repository does not redistribute those images.
